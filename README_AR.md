# MarPatients Admin V1 — تطبيق إدارة مستقل

## رفع المشروع على GitHub
1. افتح المستودع Marshal-App.
2. ارفع مجلد `admin_app` بجوار `flutter_app` الموجود بالفعل، ولا تستبدل `flutter_app`.
3. ارفع الملف `.github/workflows/build-admin-apk.yml` داخل مسار GitHub نفسه.
4. من GitHub > Actions اختر `Build MarPatients Admin APK` ثم `Run workflow`.
5. حمّل ملف `MarPatients-Admin-APK` من Artifacts وثبّت APK على هاتفك.

## الاستخدام
- أول فتح: اختر كلمة مرور جديدة لا تقل عن 8 أحرف. لا تستخدم كلمة المرور التي نشرتها في المحادثة.
- يعرض البرنامج العملاء من ملف Marshal الأصلي (266 عميلًا)، جميعهم مخفيون وغير مفعّلين افتراضيًا.
- ابحث عن عميل، عدّل اسمه، أو فعّل/أخفِ ظهوره محليًا، أو أضف عميلًا جديدًا.
- بيانات الإدارة تُحفظ **على نفس الهاتف فقط**. لا توجد مزامنة مع تطبيق المرضى أو Oracle أو سيرفر.

## حدود النسخة التجريبية وأمانها
- كلمة المرور محفوظة في Android secure storage، لكن هذه نسخة تجريبية وليست نظام صلاحيات خادم.
- لا تستخدم التطبيق لتعديل بيانات إنتاجية؛ التغييرات لن تظهر لدى المرضى.
- لا توجد استعادة لحساب المالك إذا فُقدت كلمة المرور؛ حذف بيانات التطبيق يعيد ضبط الإعدادات المحلية.
- في الإصدار الحقيقي: API مركزي + توثيق حساب المالك على السيرفر + MFA + قاعدة بيانات مركزية + سجلات تدقيق، بدون تخزين كلمات مرور في GitHub.
- بناء APK يحتاج GitHub Actions؛ لم يتم اختبار Flutter build محليًا في هذه البيئة.
